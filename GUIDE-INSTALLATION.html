Guide d'installation
Simple • Rapide • 5 minutes chrono

02 / 10
── Présentation

Ce que le bot fait pour toi

Tu n'as rien à faire. Laisse Chrome ouvert sur play-hystoria.net, il gère tout.

  • Se connecte tout seul si ta session expire
  • Vote toutes les 1h30 automatiquement
  • Ouvre serveur-prive.net et clique sur "Je vote maintenant"
  • Lit le timer de cooldown et attend le bon moment
  • Synchronise les deux onglets entre eux
  • Affiche un badge en bas à droite avec le statut
03 / 10
── Étape 1

Installer Tampermonkey

Tampermonkey est l'extension Chrome qui permet d'exécuter le bot.

1

Ouvre Google Chrome

(Ça marche aussi sur Edge, Brave, Firefox, etc.)

2

Va sur le Chrome Web Store

Cherche Tampermonkey et clique sur "Ajouter à Chrome"

→ chromewebstore.google.com/...

3

Confirme l'installation

L'icône de Tampermonkey apparaît en haut à droite de Chrome.

04 / 10
── Étape 2

Activer le mode développeur

⚠ C'est obligatoire sinon Tampermonkey ne pourra pas lancer le script.

1

Dans Chrome, va à l'URL : chrome://extensions/

2

En haut à droite, active le toggle "Mode développeur"

3

Redémarre Chrome complètement (ferme toutes les fenêtres puis rouvre)

⚠ Sans redémarrage de Chrome, le mode développeur ne prend pas effet et le bot ne fonctionnera pas.

05 / 10
── Étape 3

Installer le script du bot

Deux méthodes au choix — la première est la plus simple.

⚡ Méthode 1 — Installation automatique (recommandée)

Clique sur ce lien :

https://raw.githubusercontent.com/LLuuffyy/Bot-Hystoria/claude/dofus-auto-voting-bot-ed6is/hystoria-auto-vote.user.js

Tampermonkey va détecter automatiquement le script et t'afficher une page d'installation.

Clique sur "Install" → c'est fait !

✍ Méthode 2 — Copier-coller manuel

Si la méthode 1 ne fonctionne pas :

  1. Ouvre le lien ci-dessus (le code s'affiche)
  2. Sélectionne tout (Ctrl+A) et copie (Ctrl+C)
  3. Clique sur l'icône Tampermonkey → "Créer un nouveau script..."
  4. Efface le contenu par défaut et colle le script
06 / 10
── Étape 4 • IMPORTANT

Renseigner tes identifiants

C'est la seule partie à modifier dans le script. Tout en haut, tu verras :

// --- CREDENTIALS --- const HYSTORIA_USERNAME = 'NOM-DE-COMPTE'; const HYSTORIA_PASSWORD = 'MOT-DE-PASSE'; const SERVEUR_PRIVE_PSEUDO = 'Tomos';

Remplace les 3 valeurs par :

  • HYSTORIA_USERNAME → ton nom d'utilisateur sur play-hystoria.net
  • HYSTORIA_PASSWORD → ton mot de passe play-hystoria.net
  • SERVEUR_PRIVE_PSEUDO → ton pseudo en jeu (celui de ton perso Dofus)

⚠ Garde bien les guillemets simples '...' autour de chaque valeur.

07 / 10
── Exemple concret

Comment ça doit ressembler

Si par exemple ton compte est Bobby99 avec le mdp secret123 et ton perso s'appelle Bob-Le-Destrier:

// --- CREDENTIALS --- const HYSTORIA_USERNAME = 'Bobby99'; const HYSTORIA_PASSWORD = 'secret123'; const SERVEUR_PRIVE_PSEUDO = 'Bob-Le-Destrier';

✓ Correct

const HYSTORIA_USERNAME = 'Bobby99';

✗ Incorrect

const HYSTORIA_USERNAME = Bobby99;

(guillemets manquants)

✓ C'est tout ! Tu peux juste laisser Chrome ouvert sur play-hystoria.net et le bot votera tout seul toutes les 1h30.

10 / 10
── Besoin d'aide ?

Dépannage rapide

❌ Le badge n'apparaît pas

  • Vérifie que le mode développeur est activé dans chrome://extensions/
  • Redémarre Chrome complètement
  • Vérifie que le script Tampermonkey est bien activé (toggle vert)

❌ "Champs login non trouvés"

  • Connecte-toi manuellement une fois sur play-hystoria.net
  • Vérifie que username/password sont bien entre guillemets dans le script

❌ L'onglet serveur-prive.net ne se ferme pas

  • C'est normal, Chrome empêche parfois la fermeture auto
  • Le vote est quand même pris en compte, tu peux fermer l'onglet à la main
